QUESTION

ANSWER

What are the game’s controls?

Press A to move left and D to move right. Roll left and right to break the target blocks.

How many levels are there?

There are 3 levels of difficulties that are Easy, Medium, and Hard.

How many target blocks do you need to break?

You need to break all the blocks in each level.

ADDITIONAL COMMENTS:

This game was very fun to develop. I enjoyed the puzzle aspect of the game and how the player had to think about where to aim in order to break the blocks from a different angle. Even though the game may look simple, there is a lot of physics behind it to make the marble roll realistically. I had a problem when trying to create this but my classmate helped me figure out what was wrong. The game is a fun casual game and is something I would want to expand on in the future.  I hope you have as much fun playing this game as I did creating it!
